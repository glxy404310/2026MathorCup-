# Stale hops 跨风格预测探索：完整风格留出选型

本轮结果独立保存在 `outputs/q3_domain/stale/`，没有覆盖 `q3/` 或 `q3_optimized/` 的既有预测、迁移及验证结果。

## 1. 结果与使用边界

在 239 个非 Pils/Lager 样本上，完整留一风格验证选择了 **aging 24 维、PCA 8 维、25 个近邻、距离与训练风格均衡双重加权的局部均值模型**。其 21 风格宏平均 RMSE 为 **0.364968**，低于较优均值基线 **0.377532**；但 Pils/Lager 11 个源的诊断 RMSE 为 **0.561503**，仍劣于全局训练均值 **0.546600**，以及同协议重训的旧多输出森林 **0.530711**。

因此，这轮改善了训练风格池内部的留风格选择分数，**尚未实现 Pils 整风格预测改善**。局部模型的 bootstrap 邻域也不稳定，不宜据此替换原有部署基准或宣称真实陈旧酒花感已受保障。

Pils 标签在此前探索中已经反复查看，本轮将其严格称为**反复查看的诊断集**，不是新的测试集。全部候选清单和选型规则先冻结，再进行非 Pils 风格验证；选型结果先保存，之后才计算并保存所有候选的 Pils 表现。没有根据 Pils 标签选模型、调整截距或重选配置。

## 2. 数据、分组和选择规则

预测输入仍为既有 226 维混合化学表示：69 个校准字段与 157 个相对或变换后字段。目标只有附件 `4.csv` 的标准化 `stale_hops`。身份编号、风格、其他实测感官目标以及附件 7 评论均不作为预测输入。风格仅决定验证分组和部分候选的训练权重。

排除全部 11 个 Pils/Lager 后，余下 239 行、21 个风格，每风格 3–31 行。使用完整 LeaveOneGroupOut：每折将一个风格的全部样本留出；补值、正数尺度、校准字段的 `log1p`、1%/99% 截断、标准化、PCA 和回归器都只拟合其余风格。校准变换沿用此前已实现的训练折处理；原始森林对照只做训练折中位数补值及缺失指示。

对于风格均衡候选，某训练行所属风格有 n_s 行、当前训练集共有 N 行和 S 个风格时，赋权 `N/(S*n_s)`，使各训练风格的总回归权重相等且平均行权重为 1。预测接口仍只接收化学向量，无须提供风格。近邻模型在训练折的 aging 化学空间中补值、标准化并做 PCA8，再对 25 个近邻以“逆距离×训练风格权重”加权。

事先固定的选择分数为：

\[
J(f)=\frac1{21}\sum_s\operatorname{RMSE}_s(f)
 +0.25\frac1{21}\sum_s\left|\overline{\widehat y-y}_s\right|.
\]

先限定为可参与选型、且总体 LOSO 预测方差/目标方差至少 0.05 的候选，再按 J 最小选择；若全部未过门槛，仍保留最小分数候选但标为不合格。最终 `qualified_for_proxy` 还要求其风格宏平均 RMSE 优于两种均值基线中的较优者。它只表示训练内部的代理资格，不是新风格准确率、候选改动响应性或真实风味的保证。

R²、Spearman 和样本加权 pooled RMSE 均完整报告，但不用于选型。Brut 的四个目标值恒定，相关系数不定义；相关统计保留为空，而不是补成零。小风格内 R² 很容易失真，故不以宏平均 R² 决定胜者。

## 4. Pils 诊断与未实现的改善

模型选择完成后，按同一固定最终种子重新在 239 个非 Pils 行上拟合全部候选，只用于保留完整 Pils 诊断。

|---|---:|---:|---:|

其余全部候选保存在 `pils_diagnostic_metrics.csv` 和样本级长表中。这里的森林重训使用本轮统一最终种子，数值可与此前冻结的历史工件略有差异，不能混淆两者。局部模型的 Pils 误差没有改善，也没有利用该结果切换到最低 Pils 误差的其他候选。

持续负偏差可能涉及化学量以外的储存、氧化、检测和品评因素，但当前观察数据不能确认原因；不能用已经查看的 Pils 目标均值事后校正截距后再称为未见风格预测。

## 5. Bootstrap 与局部模型不稳定性

在选定配置上训练 60 个源排除 bootstrap 模型，每次仅从非 Pils 的 239 个全局行号中有放回抽样 239 次，重新估计训练风格权重和整个流水线。前 40 个用于候选筛选，后 20 个用于方案确定后的一次性审计，不得以审计结果重选候选。种子分别从 20272123、20273123 起逐模型递增，模型估计器种子另加 10000。最终模型种子为 20271123，LOSO 的森林种子从 20270123 加折号。

抽样保持选定配置不变，未包含算法选择、新风格组成或全部测量误差的不确定性；两组模型共享同一训练总体，并非独立实验数据。差值 95% 模型分位数不是覆盖率校准的置信上界。

未使用 Pils 标签的邻域诊断显示：

- 每个 bootstrap 的“25 个近邻”平均仅涉及 **16.54 个不同啤酒**，因为有放回抽样会产生重复行。
- 相对全量最终模型，近邻啤酒集合的 Jaccard 中位数仅为 **0.50**。
- 稀疏缺失导致各抽样拟合出的缺失指示列数在 2、3、6、7 之间变化；后续 PCA 输入几何也随抽样变化。
- 源 beer 28、119 的跨模型预测标准差约为 **0.165、0.128**，其余多数约为 0.05–0.07。

邻域诊断同时保存两种 Kish 有效数：`effective_resampled_position_count` 直接按抽样位置权重计算，重复出现的同一啤酒仍占多个位置；`effective_unique_beer_count` 先将相同原始 beer 的权重相加，再计算有效数，且不会超过不同邻居啤酒数。前者不能解释为有效独立啤酒数；后者也只是权重集中度描述，并不证明不同啤酒统计独立。上述 **16.54** 是不同啤酒的实际数量均值，未使用任一种有效数替代。

这些现象说明整体 OOF 方差门槛不足以保证迁移候选的配对差稳定。局部模型在 bootstrap 中同时改变邻居身份、重复权重和 PCA 空间，可能在候选投影后出现较强响应变化。应保留迁移审计失败，不能用放宽约束、删去源或依据审计结果重选来制造成功。

局部模型的 LOSO 分数也没有明显压过平滑候选：其相对预声明等权集成的分数均差仅 -0.001180，21 个风格配对差均值的描述性标准误约 0.00909，且仅 9/21 个风格更好。风格不是随机独立实验组，这个标准误只作差异规模诊断。若以后采用稳定性优先或一标准误差规则，应先冻结非 Pils 规则再评价，不能借此根据 Pils 误差重选。

## 6. 复现、接口及文件

从仓库根目录运行：

```bash
.venv/bin/python solution_a/src/16_q3_stale_domain.py
```

完整 21 折、14 个候选与 60 次 bootstrap 在当前环境约耗时 **42.3 秒**，树和数值库线程限制为 1。Python 3.13.15、NumPy 2.5.4、pandas 3.1.0、scikit-learn 1.9.1。

主要文件：

- `run_manifest.json, selection_result.json`：预声明清单、选型规则和 Pils 诊断前冻结的配置。
- `loso_predictions.csv`：239×14=3346 条样本级长表；包含身份元信息、global_index、method、observed、prediction、heldout_style、fold。
- `loso_metrics_by_style.csv, loso_metrics_overall.csv`：完整风格/候选指标、宏平均偏差及选择分数；同时保留样本加权指标。
- `loso_split_audit.csv`：每折全部训练/留出全局行号，便于审查整风格边界和源排除。
- `pils_diagnostic_predictions.csv, pils_diagnostic_metrics.csv`：全部 14 候选的 11 源诊断，不用于选型。
- `transfer_stale_model.joblib`：`pipeline, features, target, config, selected_config, qualified_for_proxy, train_global_indices, excluded_global_indices` 等字段；预测接口为 `pipeline.predict(X[features])`。
- `bootstrap_ensemble.joblib, bootstrap_indices.npz`：60 个模型、60×239 全局抽样下标、40/20 分工和独立模型抽样种子。
- `neighborhood_bootstrap_diagnostics.csv, neighborhood_bootstrap_summary.csv`：完全依赖化学输入的邻域变化和预测波动诊断。
- `summary.json`：固定方法标签、选择结果、全部 Pils 诊断、版本和科学边界。

为兼容此前迁移接口，`inner_oof_rmse` 字段保存本轮 pooled LOSO RMSE；本轮真正的选择量另有 `loso_macro_style_rmse, loso_macro_style_abs_bias, loso_selection_score`，不能把二者混用。加载工件前应将 `solution_a/src` 加到 Python 模块路径，使自定义变换及局部回归器能够反序列化。

已验证全部 21 折排除整风格且始终排除 11 源；3346 条 OOF 完整；60×239 bootstrap 行号全部源排除；样本风格权重与每次重采结果一致；60 模型对 250 行预测均有限；模型编号、种子及 40/20 分工互不重叠。所有目标仍在附件标准化尺度上，未恢复原始 0–6 分数。
