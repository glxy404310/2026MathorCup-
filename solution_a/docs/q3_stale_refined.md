# Stale hops 稳定监督表示与尾部预测复核

本轮单独保存在 `outputs/q3_refined/stale/`。此前的 `q3/`、`q3_optimized/` 和 `q3_domain/` 结果保持原样。

## 1. 本轮实际改进与仍未解决的问题

固定缺失指示维数、平滑回归、训练辅助感官监督、训练尾部加权，以及预声明的一标准误差稳定性规则，均已实现并运行。最终规则在 239 个非 Pils/Lager 上选择 **226 维化学输入的稳定 Ridge，alpha=1000**；最终模型没有采用辅助感官方向，辅助候选的失败也完整保留。

四个外层分组折评价整个选择器时，pooled RMSE 为 **0.419951**，低于同折旧多输出森林的 **0.427986** 和固定单目标森林的 **0.423689**。同一化学配对上的 60 模型响应噪声/信号比从此前局部模型的 **0.7761** 降到 **0.6299**。这些是同数据内部预测与稳定性的改善。

**冻结主模型的 Pils 外推仍未改善**：11 源 RMSE 为 **0.561422**，其中 beer 81 预测 **-0.097893**、观察值 **1.618167**。它不能可靠预测这一高陈旧味源样本，也不能因为迁移代理约束通过而承诺真实口感不恶化。

同时，不能把这轮概括为“所有新候选都没有 Pils 点改善”：未被选中的 `tail_ridge_aging100` 在 Pils 上 RMSE 为 **0.515735**，低于本轮重训旧多输出森林的 0.530718，也低于此前冻结旧中心的约 0.526276；其 beer 81 预测提高到 **0.084521**。但它的非 Pils LOSO 宏 RMSE **0.399305**、pooled RMSE **0.441251**，均差于相应均值基线，因此未达到事先声明的资格。Pils 已被反复查看，这个点改善只是开发诊断，不能据此事后换成主模型。

## 2. Beer 81 的数据来源与尾部困难

逐项来源审查见 `q3_beer81_audit.md` 和 `outputs/q3_refined/beer81/`：按唯一 `beer` 连接后身份及 Pils/Lager 风格一致；原化学工作簿条码精确，感官/论坛文件存在科学记数法舍入，不能由此认定错配。81 在混合化学输入中没有缺失或负校准值。

其 Stale hops 处于 250 例第 5 高；239 个非 Pils 样本中仅四个不低于它。此前 aging/PCA 局部模型的最近 25 个训练邻居，目标最大值也只有约 1.0643，局部加权均值无法达到 1.6182。全化学空间有一定风格偏移，但 aging 局部空间中的邻居并不远，说明“近邻化学相似”与“尾部陈旧感相似”并不一致，不能仅靠更换近邻随机种子解决。

论坛附件只是标准化术语数值，不提供逐条原始评论；81 的陈旧、纸板、纸张术语偏高可作语义佐证，不能当作生成谱预测特征。高 barnyard 等其他实测感官也不在推理输入中。非 Pils 中 Stale hops 与 barnyard 的高度共变支持研究训练辅助监督，但不能把源样本实测 barnyard 偷渡为预测输入，或仅凭共变认定化学预测已可靠。

没有删除 beer 81，没有按它的真实分数校正截距，也没有依据 Pils 误差重选配置。Pils 的全部结果都标为**反复查看的开发诊断**，并非新的测试集。

## 3. 固定维数的化学表示

输入继续采用既有 226 维混合表示，其中 69 项为附件校准指标，157 项为相对或变换后量。对每个训练子集重新学习：校准正数中位数尺度、`log1p`、各列 1%/99% 截断、中位数补值及化学值的均值/标准差。相对量不取逆变换，不被标成统一浓度。

新表示始终追加全部所选字段的缺失指示，并固定乘以 **0.2**，不再按某次抽样中的罕见缺失率标准化。因此，全部 226 项候选的输入始终为 **452 维**，aging 24 项候选始终为 48 维，缺失列数变化不会添加或删除模型坐标。

身份和风格不作为预测输入。风格只用于分组验证、训练风格均衡权重，以及一个预声明的“风格中心+风格内残差”候选的训练目标构造。各训练风格总权重相等，所有权重均在当前训练子集或 bootstrap 中重新计算。

## 4. 真正新增的监督候选

12 个方案在 `run_manifest.json` 中预先冻结，其中均值、旧多输出树、固定单目标树只作比较；其余九个可以进入选型。新增机制包括：

- **训练辅助监督化学表示**：将其他 44 个感官目标在训练子集按风格权重标准化，用加权多输出 Ridge100 学习化学到辅助感官的系数矩阵，再取系数矩阵的 4 或 8 个右奇异方向作为监督化学坐标，最后拟合专用 Stale Ridge10 或平滑 RBF 核岭。Stale 从辅助目标中显式剔除，所有辅助值均为训练输出。预测新谱时只需化学输入。
- **训练尾部加权**：仅按当前训练集 Stale 的 80% 分位阈值，将高尾目标的损失权重乘 2，再归一化；不根据 beer 81 的标签设置阈值或权重。
- **风格中心/风格内分解**：训练风格均值以 `n/(n+5)` 向全局均值收缩，分别拟合强正则中心模型和残差模型；推理时两者都由化学预测，不提供目标风格实测均值。
- **预定义等权集成**：稳定全化学 Ridge1000、辅助 4 维 Ridge10、尾部 aging Ridge100 三者等权平均，不学习混合权重。

辅助监督没有使用留出风格的感官标签，尾部阈值没有在全样本提前计算。全部处理均完整嵌在每个训练子集内。

## 5. 选型规则及其分组验证

完整 LOSO 使用 239 个非 Pils 样本、21 个风格。候选的初始资格同时要求：预测方差/目标方差至少 **0.05**，风格宏 RMSE 和 pooled RMSE 都优于其训练均值基线。风格评分为：

\[
J=\operatorname{mean}_s\operatorname{RMSE}_s
 +0.25\operatorname{mean}_s|\overline{\widehat y-y}_s|.
\]

在合格候选中，先取最低 J 及其风格间评分均值的描述性标准误，保留 `J≤最低J+一个标准误` 的集合。随后在训练集化学空间中，按预先固定的“第三近的不同训练行”构造真实化学配对，使用 **8 个共同的训练内 bootstrap** 衡量同一模型内部预测差的噪声/信号比，选择比值较低者；复杂度优先级只打破完全并列。最终代理资格另要求配对信号 RMS 大于 1e-4，噪声/信号不超过 1。

全量非 Pils 选型中进入一标准误差集合的三者为：

| 方法 | 8 模型响应噪声/信号 | 是否最终选择 |
|---|---:|---|
| stable_ridge_aging100 | 0.607083 | 否 |
| stable_ridge_all1000 | 0.567293 | 是 |
| equal3_supervised_ensemble | 0.569491 | 否 |

后两者十分接近，8 次抽样不足以证明唯一明显优胜；选择只是遵循冻结规则。风格也不是独立随机实验组，一标准误差宽度只作预声明的容忍规则，不是新域误差置信保证。

为评价整个选择规则，再使用四个外层 GroupKFold；每个外层训练集内部重新进行完整风格 LOSO、资格筛选、一标准误差和稳定性比较，然后在外层从未参与的风格上预测。外层四次分别选中 aging Ridge、等权集成、全化学 Ridge、等权集成，没有用外层标签重新选型。

| 四外层分组评价 | 宏风格 RMSE | Pooled RMSE | R² | Spearman | 尾部 RMSE |
|---|---:|---:|---:|---:|---:|
| 全局均值 | 0.374554 | 0.435945 | -0.003267 | -0.080706 | 1.146489 |
| 旧多输出树 | 0.366405 | 0.427986 | 0.033031 | 0.155681 | 1.128265 |
| 固定单目标树 | 0.365015 | 0.423689 | 0.052352 | 0.241418 | 1.078868 |
| **完整稳定选择规则** | **0.362152** | **0.419951** | **0.069000** | **0.267146** | **1.082624** |

尾部评估由每折训练集 90% 分位阈值定义，四外折共有 24 个尾部观察，不用全数据标签预设阈值。选择器总体误差略低于固定树，但尾部 RMSE 仍略高；不能只报总体改善。所有验证仍复用此前已探索的数据，属于内部评价，不是独立外部确认。

## 7. Bootstrap 响应稳定性与口感保证的区别

最终模型及 60 个 bootstrap 都只用 239 个非 Pils 行；每个抽样固定 239 次有放回采样，重新拟合全部训练变换和风格权重。前 40 个用于迁移筛选，后 20 个仅用于方案确定后的审计；审计后不得重选候选。

在相同非 Pils 化学配对上比较此前局部模型与本轮模型：

| 委员会 | 配对差噪声 RMS | 配对差均值信号 RMS | 噪声/信号 |
|---|---:|---:|---:|
| 此前局部/PCA/近邻 60 模型 | 0.294866 | 0.379913 | 0.776141 |
| 本轮平滑 Ridge 60 模型 | 0.076819 | 0.121955 | 0.629895 |

比值约下降 18.8%，但信号幅度也缩小，不能把较小的原始噪声全部解释成预测能力提升。两个委员会采用各自固定抽样，并非相同重采样下的配对随机实验；该表是固定化学方向上的描述性架构比较，没有参与主模型选择。

总体 LOSO 方差比 0.077332 足够通过非退化门槛，但 Pils 方差比仅 0.035978，且高尾 81 仍明显漏判。响应更平滑和模型审计更稳定，均不等于真实 Stale hops 已被正确预测，更不证明合成候选的因果风味变化。

Bootstrap 固定已选配置，未覆盖算法选择、新风格组成、未知储存/工艺因素等不确定性。有限模型差值的 95% 分位数不是覆盖率校准的置信上界。目标始终是附件标准化值，没有恢复原始 0–6 分数。

## 8. 复现与接口

运行入口：

```bash
.venv/bin/python solution_a/src/22_q3_stale_refined.py
```

本次全部候选、完整 21 风格 LOSO、四个外层分组验证、稳定性比较和 60 个 bootstrap 约耗时 **42.8 秒**，线程限制为 1。种子和全部配置写入 `run_manifest.json`；软件版本仍为 Python 3.13.15、NumPy 2.5.4、pandas 3.1.0、scikit-learn 1.9.1。

主要输出包括：

- `loso_predictions.csv, loso_metrics_by_style.csv, loso_metrics_overall.csv`：12 个方案完整 2868 条 LOSO 记录、风格及总体指标。
- `selection_result.json, selection_stability.csv, selection_chemical_pairs.csv`：冻结选择、八次抽样的稳定比较及真实化学配对。
- `nested_predictions.csv, nested_metrics.csv, nested_metrics_by_style.csv, nested_choices.csv`：四外层分组评价及每折所选模型。
- `loso_split_audit.csv, nested_outer_split_audit.csv, nested_inner_split_audit.csv`：完整训练/留出全局行号，核验风格及 Pils 排除。
- `pils_diagnostic_predictions.csv, pils_diagnostic_metrics.csv`：12 个方案对全部 11 源的开发诊断，包含 81，不删除失败源。
- `candidate_models/*.joblib, candidate_model_manifest.csv`：九个可选工件及其真实状态。
- `transfer_stale_model.joblib`：冻结主模型，含 `pipeline, features, config, qualified_for_proxy, train_global_indices, excluded_global_indices`，支持 `pipeline.predict(X[features])`。
- `bootstrap_ensemble.joblib, bootstrap_indices.npz`：60 个模型、60×239 源排除全局下标、40/20 分工和种子。
- `bootstrap_response_comparison.csv, summary.json`：稳定对照、完整数字及局限。

主模型工件明确记录 `uses_auxiliary_supervision=false`，辅助方向只属于本轮比较中未获选的方案；不能把协议测试过辅助监督误报为最终主模型采用了它。加载工件前须将 `solution_a/src` 加到 Python 模块路径。

已核验 2868 条 LOSO、956 条外层预测完整；全部 60 个最终抽样模型的输入表示固定为 452 维且对 250 行输出有限；所有抽样均排除 11 源；四外层/内层风格边界和训练范围可由审计表复查；九个候选工件全部保存而非挑选。后续迁移结果须同时报告 Tripel 接近程度、修改幅度和新旧代理审计，不能以缩小所有模型变化取代风格迁移。
