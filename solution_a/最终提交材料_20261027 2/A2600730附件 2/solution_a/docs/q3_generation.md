# 第三问：风格条件生成运行报告

运行日期：2026-10-23。

## 数据、模型与固定参数

使用 250 款啤酒、226 个混合表示特征及 22 个风格。其中 69 个字段使用附件校准值，157 个使用原文件相对表示；去除 5 个派生汇总列。负校准值视为缺失，保留真实零，按训练折中位数补缺。原始附件不作修改。

逐列用训练经验分布中秩映射到正态潜在空间。风格均值以 n/(n+5) 向全局均值收缩；协方差以 n/(n+20) 混合风格 Ledoit–Wolf 协方差与全体训练样本去风格均值后的 Ledoit–Wolf 共享协方差，另加微小对角项以保证正定。固定参数 (5,20) 在查看验证结果前声明，不以外层验证选择参数。用 (2,5) 与 (10,50) 单独做敏感性比较。

生成逆映射采用离散经验逆分布，单列取值来自补缺后的训练支持；零及检出限在逆分布中拥有非零宽度的概率区间。条件潜在分布及高斯近似会改变实际生成的零频率，不保证它精确等于全局或目标风格的经验零频率；差异另存 `generated_zero_diagnostics.csv`。新颖性来自不同列的新组合。连续潜在高斯模型仍只是对点质量依赖关系的近似。该方法输出化学目标谱，未包含配料、温度、时间或发酵控制，因此不构成可执行酿造配方。

## 无泄漏验证与结果

对全部 22 个风格做 2 次独立随机种子的分层 3 折划分，逐折重拟合补缺、经验分布、风格中心和协方差；评价 Tripel、Kriek、Lambic、Pils/Lager。每法每折 300 个生成样本，3 个 Monte Carlo 种子。比较条件 copula、目标风格训练样本 bootstrap、无条件 copula。下表先平均同折 Monte Carlo 次数，再对 6 个划分取均值；折间标准差见 CSV，由于折及重复间数据有重叠，该标准差不是独立实验置信区间。

边缘 W1 以全部训练行各列 IQR 标准化；零 IQR 依次回退训练极差、常数 1。均值保留了所有极端值的影响，另报跨特征中位数。Kriek 的均值尤其受相对特征 `X2.methyltetrahydrofuran.3.one` 的极端值支配，因此不能据平均 W1 的单项改善宣称全面优越。五维能量距离在训练 Gaussian 空间拟合的 PCA 中计算，各轴以训练标准差缩放，使用经验 V 统计量。Spearman 差为测试及风格训练中均非恒定的列之间相关系数的平均绝对差，生成恒定列的相关记 0。方差覆盖率为生成方差/目标风格训练方差落在 [0.5,2] 的特征比例，排除目标训练中恒定列；它衡量风格训练方差再现程度，不代表包含真实总体方差的置信覆盖。

- Tripel：条件模型相对风格 bootstrap 的边缘 W1 变化 +107.5%，能量距离变化 -12.2%；相对无条件模型能量距离变化 -40.3%。
- Kriek：条件模型相对风格 bootstrap 的边缘 W1 变化 -51.0%，能量距离变化 +20.2%；相对无条件模型能量距离变化 -51.6%。
- Lambic：条件模型相对风格 bootstrap 的边缘 W1 变化 +206.7%，能量距离变化 +42.6%；相对无条件模型能量距离变化 -63.0%。
- Pils/Lager：条件模型相对风格 bootstrap 的边缘 W1 变化 +136.4%，能量距离变化 +20.2%；相对无条件模型能量距离变化 -55.7%。

bootstrap 直接复制风格训练行，复制率 100%，作为高保真但无新颖性的基线；不得将条件模型在部分指标劣于 bootstrap 的结果删除。300 是每次模拟样本数，并没有将 Kriek 的 10 款真实样本扩充成 300 个独立证据；Kriek/Lambic/Pils-Lager 每折测试仅约 3–4 款，Tripel 每折约 9–10 款，边缘尾部、相关性与能量距离估计均很不稳定。尤其相关矩阵有 226 维，其留出比较只作探索性诊断。需要新增真实啤酒及实测品评验证。

## 全量拟合生成及支持域

在全部数据重新拟合后，为 Tripel、Kriek、Lambic、Pils/Lager 各保存 300 行生成谱；输出不是折外性能估计。每行另存相对风格中心的正则 Mahalanobis 距离、到所有/目标风格训练啤酒的 Gaussian 均方根近邻距离、完全复制标记。

支持阈值由全量风格样本的拟合距离 95% 分位数及风格内留一近邻距离 95% 分位数构成，用于跨风格候选的描述性筛选。它们不是覆盖率保证或独立校准阈值；中心和距离使用全量拟合，小样本阈值有明显不确定性，应同时报告候选的连续距离与是否越界。本轮全部生成谱都超过全量训练距离95%阈值，反映高维小样本模型的训练内距离明显乐观。另存折外真实样本距离和 `cv_support_thresholds.csv`，用作较宽的对照参考；它来自不同折模型，将其用于全量模型候选也没有严格覆盖率保证。所有阈值版本均保留，避免在看到通过率后隐藏不利诊断。

## 参数敏感性与复现

敏感性仅用每折相同的第一个 Monte Carlo 种子，比对已预先声明的三对固定参数。不得把敏感性最好的外层结果重新报告为无偏的调参后精度。

|均值收缩强度|协方差收缩强度|平均边缘 W1|平均能量距离|
|---:|---:|---:|---:|
|2|5|19.8424|0.6096|
|5|20|19.6278|0.7688|
|10|50|19.7829|1.0051|

本次运行耗时约 7.3 秒，线性代数线程数固定为 1。

```bash
.venv/bin/python solution_a/src/07_q3_generation.py
```

模型类接口：`ConditionalGaussianCopula(5,20).fit(X, styles)`；`sample(style,n,seed)` 返回同列顺序 DataFrame；`transform(X)` 返回 Gaussian 潜在矩阵；`inverse_transform(Z)` 返回离散经验逆映射；`distance(X,style)` 返回按特征数归一的正则 Mahalanobis 距离。全量模型保存为 `outputs/q3/generation/fitted_model.joblib`。

主要输出：`cv_metrics.csv`、`cv_summary.csv`、`cv_fold_means.csv`、`cv_mc_variability.csv`、`cv_assignments.csv`、`cv_marginal_w1_by_feature.csv`、`sensitivity_metrics.csv`、`sensitivity_summary.csv`、`generated_*.csv`、`generated_diagnostics.csv`、`full_style_support_metrics.csv`、`full_style_support_thresholds.csv`、`cv_holdout_support_metrics.csv`、`cv_support_thresholds.csv`、`generated_zero_diagnostics.csv` 与 `summary.json`。

条件生成能量距离在固定划分内的 3 次 Monte Carlo 标准差：中位数 0.0246，最大值 0.0582。它仅反映有限生成次数的随机波动，不覆盖真实风格样本少带来的估计误差。
