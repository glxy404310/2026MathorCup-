# Q1 独立验证复核与稳健性诊断

复核日期：2026-10-23。只读检查 `outputs/q1` 和 `outputs/q1_robust` 的指标、折外预测及相应源码；未修改原基线、未删除任何样本。所有误差均在附件4提供的连续感官尺度上，**不是原始0–6分误差**。

## 结果应怎样解读

| 模型/实验 | MAE | RMSE | 45维宏平均 R² | 验证性质 |
|---|---:|---:|---:|---|
| 训练折均值 | 0.409634 | 0.574456 | -0.007574 | 原始五折基线 |
| 普通岭回归 | 0.406092 | 0.589966 | -0.065285 | 原始五折，内层四折选 α |
| ExtraTrees | 0.340851 | 0.486220 | 0.214638 | 原始五折，固定超参数 |
| 1%/99%裁剪 + 岭回归 | 0.352513 | 0.499179 | 0.185784 | 发现异常后复用原五折的探索性实验 |

普通岭回归的 MAE 比均值略低，但 RMSE 比均值高约2.70%，不能笼统说“所有指标更差”。ExtraTrees 的 RMSE 比均值降低15.36%、MAE降低16.79%、均方误差降低28.36%；五个外层测试折的 RMSE 均改善，降幅11.60%–17.91%。这支持其在当前样本与风格混合范围内优于均值基线，不等于已经获得独立测试集上的确认，也不能把宏平均 R²=0.214638 写成“准确率21.46%”。

ExtraTrees 在45个目标上的 R² 都高于均值基线，44个目标 R²>0，29个目标 R²>0.1，19个目标 R²>0.2。强弱明显不均：Taste 30维宏平均 R²=0.235783，Aroma 15维=0.172350；原表单 numeric 属性为0.276281，categorical 子描述符为0.160701。这是预测难度差异的证据，不是化学机理或标签错误的证明。

## 岭回归劣化集中于一个极端特征样本

`beer=156`（Kriek，外层第1折）的 `X2.methyltetrahydrofuran.3.one` 为 **12596.43287**；该折训练数据此特征最大值为31.25344244，样本标准差为3.23648240，相对训练中位数偏离约3892个训练标准差。标准化不会限制极端测试值；线性模型会外推，强正则也未完全抑制这种外推。

该酒45维平均平方误差如下：

| 预测 | 45维平均平方误差 |
|---|---:|
| 均值 | 0.787131 |
| 普通岭回归 | 8.651434 |
| ExtraTrees | 0.597805 |
| 20%遮蔽后的普通岭回归 | 0.721929 |
| 裁剪后岭回归 | 0.635978 |

普通岭回归对此酒的 `acetic` 预测为12.000390，观测值为-0.280484；`acidity` 预测6.338958，观测值0.212311。该样本相对均值的超额平均平方误差为7.864303，而250酒超额误差之和仅4.515137，因此其他249酒合计仍有改善。

作为**事后误差贡献诊断**，仅从指标汇总中暂不计该点时，普通岭回归 RMSE=0.560993，均值 RMSE=0.572856；这不是删除数据后重训的实验，也不应替代包含全部250酒的正式指标。该数值只说明原岭回归的总体劣化由极端外推主导。尚无依据将该样本判为错误数据，原附件数值与官方数据源一致；保留样本并检验对极端值不敏感的方法更合适。

## 20%缺失遮蔽“改善”不是缺失有益

原代码对同一折生成同一组均匀随机数，令10%掩码成为20%掩码的子集。上述极端单元格对应的随机数为 **0.1670929808**：10%掩码不隐藏它，20%掩码恰好隐藏它，随后使用训练折中位数插补。

因此该酒普通岭回归的平均平方误差从8.651434降至0.721929，改善7.929505。全部250酒的平均平方误差之和改善仅7.360157，说明其他249酒合计反而变差。普通岭回归20%遮蔽 RMSE 从0.589966降至0.564464，应解释为“一次随机遮蔽偶然移除了极端外推驱动值”，不能解释成“缺失20%时模型更准确”或一般性稳健优势。

ExtraTrees 的变化更平滑：无新增遮蔽、10%、20%时 RMSE 分别为0.486220、0.490987、0.499218，后两者相对增加0.98%与2.67%。这只检验一次随机隐藏已观测协变量的压力情景；没有覆盖按检出限删失、特定仪器故障、成组缺失或分布外新酒。

## 裁剪后岭回归：已完成的事后稳健实验

`02b_q1_robust.py` 将逐特征1%/99%分位裁剪放在 Pipeline 内，与中位数插补、X/Y标准化及 α 选择一起在每个内层训练折重拟合。`common.py` 中 `QuantileClipper.fit` 只使用输入训练数据学习边界，`transform` 不使用目标值；外层测试样本没有参与边界估计。未发现此实现新增的直接测试数据泄漏。

全部250酒保留。复用原五折后，稳健岭回归 RMSE=0.499179，比均值低13.10%，比普通岭回归低15.39%，仍高于 ExtraTrees 的0.486220；宏平均 R² 提升到0.185784。五折所选 α 均为1000。第1折该极端特征的上界为19.311161，beer156的45维平均平方误差降至0.635978，其 acetic 预测为0.759129，极端外推显著缓解。

稳健岭回归45个目标 R² 均为正，在16个目标上优于 ExtraTrees。例如 `orange` 为0.225657（ExtraTrees为0.112159），`A_esters_fruity` 为0.050311（-0.010524），`F_esters_fruity` 为0.123188（0.073220）。这些结果提示可以进一步研究不同模型适用的属性；不能直接依据同一批折外结果挑出每个目标的获胜模型，再把拼接结果当作未受选择偏差影响的测试性能。

新增10%与20%遮蔽后，稳健岭回归 RMSE 分别为0.507932和0.514142，相对增加1.75%和3.00%，原普通岭回归的反常改善消失。

**验证边界：** 分位裁剪是在查看原五折错误后提出，尽管每次拟合遵守折内处理，方法设计已经受到这批测试结果启发。因此这些数字是探索性稳健性证据，不是新独立留出集上的确认。固定1%/99%裁剪还可能压缩真实稀有成分；后续应冻结方法，再进行预先确定的重复交叉验证或独立样本验证，并单独检验跨风格泛化。

## 0–6不可辨识与相对等级的准确措辞

建议阶段说明写为：

> 本阶段完成了45个感官属性在附件4所给标准化连续尺度上的预测及初步验证。原始评分按品评员标准化后汇总；现有附件和已检查的官方公开数据未提供足以逆变换的逐人评分、标准化参数与参与关系。因此真实0–6量尺的还原与该量尺上的误差验证尚未完成。

可以附加明确标记的“参考分布相对等级 L0–L6”，但这只是新的展示或决策量尺：

1. 明确公开锚点、阈值、取整和截断规则；使用分位数时称“分位锚点”，不能声称0代表未检出、6代表压倒性强度。
2. 与标准化连续预测并列保留，单独标注“人为定义的相对等级，未经原始0–6评分校准”。
3. 若在交叉验证中评估这种等级，阈值只能由训练数据拟合；评估对象仍是相对等级代理任务，不能命名为原始评分准确率。
4. 只有引入独立实际评分样本或可靠的物理/感官锚定证据，并另做校准验证，才可以讨论原量尺上的预测；即使如此也不等于恢复已经丢失的逐人历史评分。

当前没有生成这些等级，也不应借此将原始0–6要求标记为已完成。
