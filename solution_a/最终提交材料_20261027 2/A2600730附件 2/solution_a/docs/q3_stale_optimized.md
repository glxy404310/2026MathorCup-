# Stale hops 单目标代理优化与复核

运行日期：2026-10-23。所有新结果位于 `outputs/q3_optimized/stale/`，原第三问结果和模型保留。

## 1. 实际结论

专注 `stale_hops` 的固定单目标 ExtraTrees 对照优于旧 45 目标联合森林，但当前嵌套多模型选择算法没有稳定超过旧代理，Pils/Lager 整风格留出的预测也没有改善。因此，这轮实现建立了可审计的专用模型与更严格验证，**尚不能宣称跨风格 Stale hops 预测已经可靠**。

在新声明的两个随机种子、每个五折的重复折外验证中：

| 方法 | RMSE | R² | Spearman | 预测/目标方差比 |
|---|---:|---:|---:|---:|
| 训练折均值 | 0.442356 | -0.007738 | -0.096170 | 0.000860 |
| 旧 45 目标 ExtraTrees，取 stale 输出 | 0.434276 | 0.028741 | 0.205536 | 0.029634 |
| 固定单目标 ExtraTrees | **0.424753** | 0.070870 | 0.301098 | 0.110167 |
| **预声明嵌套选择算法（主结果）** | **0.438172** | **0.011233** | **0.197368** | **0.119944** |

主算法 RMSE 相对均值仅下降 **0.95%**，相对旧多输出模型反而增加约 **0.90%**。固定单目标森林的对照结果相对均值下降 **3.98%**、相对旧模型下降 **2.19%**，说明共享 45 个目标的树分裂确会牺牲该单项，但不能把对照中的最低外折误差替换成嵌套算法的无偏主结果。

两个种子下主算法的 RMSE 分别为 0.440293、0.436041；固定单目标森林分别为 0.425978、0.423524。完整逐种子及逐折结果均保留，未只选有利切分。

## 2. 数据与折内预处理

沿用 `q3_data.load_q3_data()` 的 250×226 混合化学表示，其中 69 个校准原值、157 个相对或已变换表示；缺失和无效值处理遵循既有数据契约。唯一预测目标是 `4.csv` 的附件标准化 `stale_hops`，不使用其他实测感官目标、附件 7 评论、身份编号或风格作为预测特征。旧多输出对照仍用 45 项作为训练输出，其预测输入也只有化学字段。

为处理量纲与极端值，新候选流水线依次执行：

1. 使用预先声明的全部 226 项，或附件化学元数据指定的 aging 子集。
2. 对校准字段学习训练子集的正数中位数尺度，做 `log1p(x / scale)`；零值保留，负校准值不允许输入。相对表示不取逆变换。
3. 在同一训练子集学习各字段 1%/99% 分位截断界限。
4. 在训练子集拟合中位数补值、缺失指示和 StandardScaler。
5. 训练相应单目标回归器。

以上每一步均放入 sklearn Pipeline，每个内折、外折以及每次 bootstrap 都重新拟合。没有在全数据上先算尺度、截断界限、中位数或监督特征筛选。

aging 子集只按 `8.xlsx / Sensory thresholds` 中 `aging` 非空且 `field_name_R` 精确落在 226 列中的字段确定。附件有 26 条 aging 字段，精确相交得到 **24 项**，冻结在 `predeclared_aging_features.csv`。该子集没有根据本次感官目标相关性筛选，也不是完整的陈旧酒花感机制证明。

## 3. 预声明候选与嵌套选择

外层为两个固定种子 `20261123, 20262123`，每个使用 shuffled 五折；每个外层训练子集再用三个 shuffled 内折。18 个候选在外层结果产生前写入 `run_manifest.json`：

| 模型家族 | 固定的小网格 |
|---|---|
| Ridge | alpha 10、100、1000 |
| ElasticNet | alpha 0.01、0.1；l1_ratio 0.5 |
| PLS | 3、8 个成分 |
| RBF-SVR | C 0.3、1、3；epsilon 0.05；gamma scale |
| 单目标 ExtraTrees | 160 棵；叶节点最少 3、8；max_features 0.7 |
| RandomForest | 160 棵；叶节点最少 3、8；max_features 0.7 |
| GradientBoosting | 150 棵；learning_rate 0.03；depth 2；平方损失或 Huber |
| aging 子集 | Ridge alpha 10；RBF-SVR C 1 |

内层先要求 OOF 预测方差/目标方差至少为 **0.05**，即标准差比至少约 0.224，再在符合条件者中选择 OOF RMSE 最小的候选。若全部未达到门槛，仍保存最小 RMSE 结果，但标记非退化资格不通过。每个外折分别在其训练数据内部作出选择，外折测试结果不进入选择。

同时保存七个家族各自的嵌套选择结果，方便诊断；这些家族的外折结果没有用于重选最终迁移配置。固定单目标森林对照使用 300 棵、min_samples_leaf 3、max_features 0.7、原始混合表示上的折内中位数补值，保持与旧多输出基线的结构差异集中在训练目标。

**非退化门槛只是一项资格筛查。** 不同外折/内折训练均值的变化也会贡献 OOF 方差；整体预测方差足够不代表模型对某个候选化学改动有响应。迁移阶段还须检查配对预测差的跨候选离散度、零差比例以及所选方案至少有模型给出非零变化，不能用几乎恒定的预测轻易通过约束。

## 4. 最终迁移代理：239 例训练，11 个源完全留出

最终配置的选择重新在 **239 个非 Pils/Lager 样本**内部作三个内折，种子 `20263123`。全部 11 个 Pils/Lager 源不进入这个模型的训练、调参、截断、补值、尺度学习或 bootstrap 抽样。此选择使用同一预声明网格与非退化规则，不根据前述全样本外折结果或 11 源留出效果选择模型。

实际选中配置为 **aging 24 项的 RBF-SVR，C=1、epsilon=0.05、gamma=scale**。它的 239 例内层 OOF RMSE 为 **0.428776**，同折训练均值为 0.436728；预测方差比为 **0.136348**。`qualified_for_proxy=True` 的含义严格限定为：训练内层 OOF 通过方差门槛并优于其均值基线。由于它是 18 个配置比较后的获选指标，仍有选择乐观偏差，不能当作新的独立外测精度。

模型选好后，才计算 11 个 Pils/Lager 源的整风格留出结果：

| 模型 | RMSE | R² | Spearman |
|---|---:|---:|---:|
| 非 Pils 训练均值 | 0.546600 | -0.124074 | 常数预测，不定义 |
| 旧多输出迁移代理 | 0.526276 | -0.042038 | 0.418182 |
| 新单目标 SVR | **0.550652** | **-0.140802** | **0.409091** |

**新模型在这 11 个源上的 RMSE 劣于均值与旧模型。** 它对该留出风格的外推能力尚不受支持。留出样本仅 11 个且属于同一风格，不宜从相关排序分数得出强结论。该负面结果完整保存，没有以留出结果重新调参或换成另一个模型。

因此 `qualified_for_proxy` 只允许后续运行模型内的约束和灵敏度研究，不能解释为真实风味质量已通过验证。模型文件中的 `qualification_scope` 显式标记 `training_only_inner_CV; not holdout or counterfactual validation`；summary 另存 `pils_holdout_improves_mean=false`。

## 5. 60 个配对 bootstrap 模型

在最终 239 例内 CV 选中的同一配置上固定结构，不再调参，分别建立：

- **40 个候选筛选模型**：抽样种子 `20264123 + b`，b 为 0 至 39。
- **20 个一次性审计模型**：抽样种子 `20265123 + b`，b 为 0 至 19。

每次从 239 个非 Pils 行中有放回抽 239 次，重新拟合整个预处理和 SVR 流水线；若回归器包含随机参数，其估计器种子另设为该抽样种子加 10000。所有抽样的原始 250 行全局下标均保存，已验证 60×239 下标全部排除源。两组抽样种子和模型编号完全不重叠，但仍共享同一训练总体，**不构成新的独立实验数据**。

每个模型分别预测源和候选，取同一模型内部的配对差：

\[
\Delta_b=f_b(x_{candidate})-f_b(x_{source}).
\]

前 40 个模型可以参与候选筛选；后 20 个模型仅在方案确定后审计一次，不得根据审计结果重新选择候选。有限模型抽样的差值 95% 分位数不是覆盖率校准的置信上界。本 bootstrap 固定获选配置，**未包含调参/算法选择的不确定性**；它也没有覆盖未知测量偏差、生成谱分布偏移和模型失配。

候选配对差满足不增加，仅说明这些拟合代理和该抽样口径下指标未增加。当前整风格留出表现不佳，更不能把约束通过解释为真实陈旧酒花感已经改善或得到保障。

## 6. 接口、输出与复现

从仓库根目录运行：

```bash
.venv/bin/python solution_a/src/12_q3_stale_optimized.py
```

完整训练、十个外折的内层比较、末尾 60 次 bootstrap 在当前环境约耗时 **72.8 秒**，限制数值库及树模型线程为 1。当前版本为 Python 3.13.15、NumPy 2.5.4、pandas 3.1.0、scikit-learn 1.9.1。

输出文件包括：

- `run_manifest.json`：所有预声明候选、字段、种子、内外折规则和方差门槛。
- `nested_inner_cv_results.csv, nested_selected_configs.csv`：每外折的全部内层候选与选择结果。
- `oof_predictions.csv, metrics.csv, metrics_by_fold.csv`：全部方法、两种子、每折及重复汇总结果。重复汇总的 500 条 OOF 是同一 250 例的两次预测，不能视为 500 个独立啤酒样本。
- `transfer_inner_cv_results.csv, transfer_selected_inner_oof.csv`：239 例最终配置选择及训练内 OOF 记录。
- `pils_style_holdout_predictions.csv, pils_style_holdout_metrics.csv`：11 源风格留出预测、均值与旧模型对照，结果未用于选型。
- `transfer_stale_model.joblib`：`pipeline, features, target, selected_config, qualified_for_proxy, inner_oof_variance_ratio, inner_oof_rmse, train_global_indices, excluded_global_indices`。
- `bootstrap_ensemble.joblib`：60 个 `models`、全局 `bootstrap_indices`、抽样/估计器种子、`selection_model_indices=0..39`、`audit_model_indices=40..59`，以及相同的特征、目标和资格元数据。
- `bootstrap_indices.npz, summary.json`：抽样数组和完整摘要。

加载模型时须把 `solution_a/src` 加到 Python 模块路径，以便反序列化 `q3_stale_optimized.FoldChemicalTransform`。输入仍为既有 226 列的 DataFrame 或同顺序矩阵；aging 子集选择内置于流水线中，调用者不应先截成 24 列。

已验证：最终模型和全部 60 个模型对完整输入输出有限；226 列顺序一致；训练/排除下标互斥；全部 60 个 bootstrap 排除 11 源；40/20 模型分组与 60 个抽样种子不重叠。原始 0–6 感官量表未被恢复，所有分数仍是附件提供的标准化目标。

## 7. 固定单目标森林的额外切分复核

独立脚本 `src/12b_q3_stale_fixed.py` 将固定单目标森林与旧多输出森林、训练均值放在另外两个五折种子 `20263123, 20264123` 上比较。参数始终固定为 **300 棵树、min_samples_leaf=3、max_features=0.7**，预处理只用训练折中位数补值及缺失指示，没有重新选择特征、变换、模型家族或参数。输出保存在独立目录 `outputs/q3_optimized/stale_fixed/`，没有覆盖上面的 18 候选嵌套结果。

这是一项固定参数的后续内部验证：研究者已经看到同一 250 例上的探索性算法比较，然后才选择继续检验专用森林。新增切分种子没有产生独立新数据，因此不能把这轮结果称为完成了独立外部确认。

| 两个新切分的重复 OOF | MAE | RMSE | R² | Spearman | 预测/目标 SD 比 |
|---|---:|---:|---:|---:|---:|
| 训练折均值 | 0.309059 | 0.442568 | -0.008705 | -0.102510 | 0.031101 |
| 旧多输出森林 | 0.303986 | 0.436006 | 0.020987 | 0.191081 | 0.185672 |
| 固定单目标森林 | 0.293400 | **0.432300** | 0.037557 | 0.259944 | 0.340940 |

固定单目标森林相对旧模型的 pooled RMSE 仅下降 **0.85%**。种子 20263123 下，它反而略差：0.435387 对 0.434728；种子 20264123 下为 0.429191 对 0.437280。结果表明优势对切分敏感，不能用先前两个切分中较大的改善代替全部复核结果。

配对抽样以 **beer 为聚类单位**：先对每个啤酒、每种方法的两次 OOF 平方误差取平均，再有放回重采 250 个 beer，共 2000 次，随机种子 20269123。没有把重复 OOF 的 500 行当作独立样本。

- 固定单目标减去旧模型的 RMSE 差为 **-0.003706**，bootstrap 95% 百分位区间为 **[-0.015646, 0.009670]**。
- 相对 RMSE 下降为 **0.85%**，95% 百分位区间为 **[-2.39%, 3.65%]**。

两个区间均跨零，当前数据不能支持稳定优势。它们只是条件于已保存 OOF 预测的抽样不确定性描述：2000 次抽样未重新训练森林，没有重现同数据上的算法选择过程，且不同啤酒的预测还共享交叉验证训练折，不能将区间当作完整的选择后推断。

固定模型随后按预声明参数训练于 239 个非 Pils 样本。其训练内三个折的 RMSE 为 **0.430709**，方差比 **0.121108**，通过训练内部的代理资格门槛；但 11 源整风格留出 RMSE 为 **0.559206**，仍差于均值 0.546600 和旧模型 0.526276，R² 为 **-0.176522**。因此固定单目标树同样未证明源风格外推已经改善。

此目录保存与前述相同接口的 `transfer_stale_model.joblib` 和 `bootstrap_ensemble.joblib`，供固定专用树的后续迁移实验使用。全量 239 例最终模型为 300 棵树；60 次 bootstrap 按要求使用 120 棵树作模型抽样近似，前 40 供筛选、后 20 供一次性审计。抽样种子分别为 `20267123+b` 与 `20268123+b`，每组 b 从零开始，所有抽样均排除 11 个源。较少树数的 bootstrap 近似及同数据算法探索均已写入限制。

复现命令：

```bash
.venv/bin/python solution_a/src/12b_q3_stale_fixed.py
```

本次训练约耗时 **27.4 秒**。额外的 `paired_cluster_bootstrap.json` 保存 beer 聚类抽样结果，`metrics.csv` 仍完整包含每个种子和重复汇总；`summary.json` 保留源留出没有超过均值及旧模型的结果。
