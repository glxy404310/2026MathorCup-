# 第三问生成模型优化：局部风格边缘与嵌套选择

运行日期：2026-10-23。使用 250 款啤酒、226 个混合特征（69 个校准字段与 157 个相对字段）。旧第三问结果完整保留，本轮文件单独位于 `outputs/q3_optimized/generation/`。

## 优化针对的问题

旧模型对全部风格共用单列经验边缘，并把小风格均值向全局收缩。Kriek、Lambic 分别只有 10、11 款真实样本，风格差异可能在这两步被稀释。本轮把风格边缘与相关结构分开处理，保持小风格的观测边缘，仍用收缩相关矩阵共享信息。

在查看本轮外层结果前固定三个候选：

1. `style_margin_copula`：各风格分别拟合经验边缘和中秩正态分数；局部 Ledoit–Wolf 相关以 n/(n+10) 的权重混合全部训练风格正态分数的共享相关。相关矩阵对角归一到 1，从零均值 Gaussian 抽样后用风格局部离散经验逆分布输出。
2. `style_smoothed_mixture`：使用相同边缘和相关，从风格训练行的正态分数中抽一个中心，加标准差固定为 0.45 的相关 Gaussian 噪声；该噪声强度固定，不搜索近零扰动。
3. `legacy_copula`：旧条件 copula 固定参数 (5,20)，作为可被内层选择的保守退路。

各风格中位数补缺，风格某列全缺失时回退全部训练行中位数；所有统计量均只用当前训练折。局部逆分布中的零拥有概率区间，Gaussian 候选在标准正态边缘下按期望再现风格训练零频率，平滑混合候选不保证相同频率。相对字段中的数值零也可能只是原表示的基准，不能全解释为物质不存在。

## 训练内选择与外层检验

外层采用预先固定的 20261123、20262123 两个种子的 22 风格分层 3 折划分。每个外层训练集再按全部训练风格做分层 2 折，分别为四个评价风格按内层平均五维能量距离选方法。候选必须在每个内折都无整行复制、生成/真实留出近邻距离中位数比至少 0.35，且与最近训练行相等的特征比例中位数不超过 95%；bootstrap 只作基准，不参与选择。复制检查同时比较完整补缺向量，以及仅比较训练行原本有观测的各列，避免不同中位数补缺掩盖原观测的整行复制。若无方法通过则退回旧模型，并保留失败诊断。

内层和外层中，同一数据划分的所有候选、被选方法及 bootstrap 均使用同一旧 copula 在该训练折拟合的全局 rank 变换、五维 PCA 和 PCA 标准差作评价坐标。没有用各候选自己的局部 CDF 或 PCA 计算可比较能量距离。每个外层方法每风格生成 300 行，使用两个 Monte Carlo 种子；先平均同折的 Monte Carlo，再汇总 6 个划分。

## 使用与限制

全量模型使用同样的训练内选择，保存为 `fullmodel.joblib`，接口为 `OptimizedStyleGenerator().fit(X,styles)` 及 `sample(style,n,seed)`，返回原 226 列顺序。另存四风格各 300 行生成谱（含 sample_id、target_style 元信息）、完整内层与外层记录、所有候选的外层比较，以及生成零频率诊断。

全量 250 行模型只用于生成画像。迁移验证应在去除源风格之后重新拟合，不能复用这个全量生成器；迁移风格距离仍由旧模型定义，保证新旧比较的量尺一致。

风格局部经验边缘不外推，也无法补足未观测的尾部；小风格中每列只有数个取值，相关与零频率估计不稳定。生成谱是化学目标组合，仍需酿造可行性、理化检测和感官实测验证。

```bash
.venv/bin/python solution_a/src/11_q3_generation_optimized.py
```
