# Beer 81误差来源诊断

beer81的高残差目前不能归因于标签错误。附件键连接、风格和可核验条码一致；无缺失、负校准值或重复化学行解释该误差。陈旧描述在论坛术语表中也处高位。直接观察到的困难是高stale尾部样本很少，且未落入现有化学近邻空间。

## 连接与测量检查

1.csv与8.xlsx校准表的完整条码为8715608222557，风格均Pils/Lager。4.csv与7.csv提供的8.71561E+12与其打印精度一致；它们是舍入后的身份信息，实际按唯一beer键连接，未采用舍入条码连接。

原231化学列缺失数为0，226混合输入缺失数为0，负校准值为0，其他样本中的整行化学重复为0。原始表示中的负值不能直接视为负浓度；混合输入的未校准相对字段仍保留其供应表示。

原表有多个字段重复同一低值，完整清单见beer81_repeated_original_values.csv。附件未提供分析LOD/LOQ，不能把共同低值直接命名为检出限；8.xlsx给的是感官阈值，也不等于仪器检测上下限。经验最小值、最大值与0值仅作为观测支持诊断保存。

81有28个相对字段重复同一低值，重复数量仅处250款的67.6%位置，并非该现象最严重的样本。

## 尾部稀缺与邻域错位

81的stale=1.618167，在250款中第5高；239款训练中仅4款不低于它。16实际局部模型的最近25训练邻居stale最高只有1.064328，低于81实测值；其预测为-0.112799。局部加权均值受邻居目标凸包限制，因此现有邻域结构无法给出81的高标签。

全226旧copula的最近邻同样多为低stale样本。完整近邻及其真实目标保存，而非只展示支持结论的邻居。这说明现有化学距离不足以组织该尾部目标，不能证明不存在其他可预测化学组合；当前附件也无法核验储存、包装、批次或品评个体差异。

## 其他感官与论坛描述

其他实测感官仅用于解释。所有50项值与239款非Pils中的stale相关均保存，它们不会作为源样本的chemical-only预测输入。论坛7.csv是数值描述符表，未提供原文、评论人数、时间或逐批次对应信息；字段数值不能解释为词出现次数。

8.xlsx明确stale_hops与barnyard均为numeric，不能把它们当作categorical父类继承值。两者在239款非Pils中的Spearman相关为0.9646；这是很强的共同变化，但没有原始品评记录来区分共享感官因素或数据加工来源，不能据此判错。

numeric说明数据类型，不代表恢复了0–6原始评分；本诊断始终保留4.csv供应的标准化表示。

这些陈旧、纸板、纸张相关描述构成另一供应数据通道的相符证据，支持谨慎保留高stale标签；但其采样是否与品评完全独立、是否对应同一批次均不明，不能称为独立真值认证。

论坛barnyard描述并不高，两个通道并非所有感官属性逐项相符；完整186项记录均已保存，没有仅保留支持高stale解释的字段。
