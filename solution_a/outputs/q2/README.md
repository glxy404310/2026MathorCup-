# 第二问首轮关联分析

本目录由 `solution_a/src/03_q2_network.py` 生成。计算结果与 scipy 成对相关计算进行数值核对。重跑：

```bash
.venv/bin/python solution_a/src/03_q2_network.py --bootstraps 200 --seed 20261023
```

数据为按 beer 一对一连接的 250 款啤酒；全图 231 节点、Top-3 候选 218 项、感官目标 45 项。所有计算在附件既有数值表示上进行，没有统一取指数或把连续标签伪还原为 0–6 分。

| 文件 | 用途 |
|---|---|
| network_nodes.csv | 全节点名映射、来源/单位/阈值及各阈值度数、加权度数 |
| network_edges_rho_*.csv | 绝对相关阈值 0.6/0.7/0.8 的有符号网络 |
| top3_compounds.csv | 每个感官维度按绝对 Spearman 相关选择的 3 个候选 |
| all_candidate_stability.csv | 全部 218×45 候选的相关、bootstrap 入选频率、分位区间和风格敏感性 |
| method_sensitivity.csv | Pearson 替代和去风格均值后的 Top-3/Jaccard |
| summary.json | 样本、阈值、网络、稳定性、数值校验及限制摘要 |

2.csv 与全样本 Spearman 矩阵最大差 6.66e-16，故它是当前样本导出的描述性网络；预测交叉验证时必须仅在训练折重建。全样本图可解释 Top-3 的邻域和相关冗余，但本轮未拟合图正则化模型。阈值 0.6/0.7/0.8 是稀疏化参数，不是显著性阈值。

Bootstrap 为 200 次全样本行重采样，重新排名，固定种子 20261023，频率最大蒙特卡洛标准误 0.0354。并列时按附件特征顺序打破。区间为相关系数的描述性 bootstrap 分位数，不是选择后推断保证。去风格均值对 X、Y 都在当前表示上按风格减均值后计算 Spearman，只检查风格间均值混杂。

本目录结论是**关联候选，不是因果因素**；稳定性不等于化学合理性。`8.xlsx` 元信息仅作附件证据，逐条机制文献验证尚未完成。`5.csv/6.csv` 和预计算 GBM/SHAP 未用于筛选。Top-3 的所有 135 项中，入选频率 ≥0.8 的有 14 项；Spearman/Pearson 平均 Jaccard 为 0.222，去风格均值前后为 0.160。这些是全样本解释稳定性，不是未见啤酒预测性能。
