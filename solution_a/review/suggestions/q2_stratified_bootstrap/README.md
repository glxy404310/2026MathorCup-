# Q2固定风格比例的分层bootstrap

这是在查看原Q2成果后补做的探索性检查，未替换原135项Top-3或冻结输出。2026-10-24在数值锁定环境运行200次，种子20261023，耗时7.24秒。

脚本直接复用`src/03_q2_network.py`的成对完整观测Spearman、Top-3排名和Jaccard函数。218个候选、45个目标及并列规则完全相同，未补值。每次在22个风格内部独立有放回抽取原来同样数量的酒，保留250款样本的既有风格比例。各风格按其在原附件中首次出现的顺序拼接；行号和选择下标已另存，便于复核。

| 指标（原135个Top-3位置） | 原全局行bootstrap | 固定风格比例bootstrap |
|---|---:|---:|
| 次数 | 200 | 200 |
| 平均入选频率 | 0.4552 | 0.4839 |
| 中位频率 | 0.400 | 0.435 |
| 入选频率≥0.8的位置 | 14 | 19 |

逐位置频率变化的平均绝对值为0.0430，最大为0.180。以“入选频率前三”另作敏感性摘要，45项目标中10项的全局/分层集合不同，平均Jaccard为0.8889；分层频率前三与原Spearman前三相比，34项目标完全相同，11项目标替换一项，平均Jaccard为0.8778。这个集合是bootstrap频率排序结果，不是新的全样本Spearman排名；原全样本135项集合经重算完全匹配，保持不变。

| 案例 | 原频率 | 分层频率 | 已有风格去均值后ρ |
|---|---:|---:|---:|
| `X4vg`—`X4VG` | 0.875 | 0.890 | 0.4280 |
| `F_esters_ethac`—`ethyl_acetate` | 0.980 | 0.985 | 0.2705 |
| `F_malt_all`—`ethanol..v.v.` | 0.960 | 1.000 | −0.0111 |

固定混合比例后，麦芽总体—乙醇仍每次入选，但其风格内关联近零。这个对照直接说明：**分层bootstrap提高频率，不能说明风格混杂已消除，更不能证明气味机制。** 4VG和乙酸乙酯的结果则与现有较强的风格内相关和直接气味依据相互补充。

新增跨过0.8的五项为：`A_hops_all`—辛酸乙酯、`F_esters_all`—乙醛、`F_esters_isoaa`—正己醇、`F_hops_all`—辛酸乙酯、`F_malt_cara`—乙醇。原来14项均未跌到0.8以下。阈值附近的一些变化很小，200次时单个频率的最大蒙特卡洛标准误约0.0354，不对这些频率差作显著性结论。

固定风格比例只改变重抽样设计，不增加真实样本量、不控制未测工艺因素。当前最小风格仅3款；若风格只有1款，每次只能重复同一行，无法估计该类内部不确定性；本附件没有单样本风格。相同种子也不代表两种抽样过程逐次配对。

## 复算

从仓库根目录，以按`solution_a/requirements-lock.txt`建立的环境运行：

```powershell
.\.venv\Scripts\python.exe -X utf8 solution_a/review/suggestions/q2_stratified_bootstrap/run_bootstrap.py
```

实际环境为Python3.13.9、numpy2.5.4、pandas3.1.0、scipy1.18.1、scikit-learn1.9.1；脚本只向所在目录写文件。原始附件1/4、Q2完整候选和Top-3表、Q2摘要及被复用源码的运行前后SHA256完全一致。
